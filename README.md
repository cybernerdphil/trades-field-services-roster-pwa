# Trades Field Services Roster PWA

A Progressive Web App (PWA) for managing rosters in the Trades Field Services industry.

## Features
- Offline functionality
- Roster management
- Responsive design

## Installation
1. Clone the repository: `git clone https://github.com/cybernerdphil/trades-field-services-roster-pwa.git`
2. Open `index.html` in a browser or serve via a local server.

## Usage
- Add/edit roster entries.
- Install as PWA for mobile/desktop.

## Technologies
- HTML, CSS, JavaScript
- Service Worker for offline support
